Fase 2 • Infraestructura Cloud

Arquitectura del Sistema en Microsoft Azure

Flujo desacoplado y sin servidor (Serverless) desde el control de versiones local hasta la entrega global con alta disponibilidad y certificado SSL automático.

Paso 1

Repositorio Git

Control de versiones en rama main en GitHub. Detección automática de cada git push.

Paso 2

GitHub Actions

Runner en la nube que valida sintaxis, comprime artefactos y ejecuta el pipeline de CI/CD automatizado.

Paso 3

Conexión Segura

Autenticación por Service Principal / Token secreto cifrado en GitHub Secrets sin credenciales expuestas.

Paso 4

Azure Storage / SWA

Almacenamiento en contenedor $web de Azure Blob Storage o Azure Static Web Apps con CDN mundial.

Escalabilidad

Serverless Puro

Capaz de absorber miles de peticiones concurrentes por segundo sin necesidad de balanceadores de carga manuales ni escalado vertical de servidores.

Disponibilidad

SLA 99.99% Global

Almacenamiento con replicación redundante (LRS/GRS) y entrega mediante puntos de presencia (PoP) de baja latencia con HTTPS preconfigurado.

Seguridad

Superficie de Ataque Cero

Al no existir sistema operativo subyacente ni servicios expuestos (como SSH o RDP), se eliminan vulnerabilidades de kernel y parches de seguridad.

Fase 3 • Automatización DevOps

Flujo de Integración y Despliegue Continuo (CI/CD)

El archivo de configuración YAML detecta eventos push en la rama principal, prepara los artefactos estáticos y sincroniza la entrega hacia Microsoft Azure sin intervención humana.

.github/workflows/deploy-azure.yml 
name: Deploy Static Web to Azure

on:
  push:
    branches:
      - main
  workflow_dispatch:

permissions:
  id-token: write
  contents: read

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: 1. Descargar Código Fuente
        uses: actions/checkout@v4

      - name: 2. Validar Artefactos Estaticos
        run: |
          echo "Verificando archivos a desplegar..."
          ls -la
          test -f index.html || exit 1

      - name: 3. Iniciar Sesion en Microsoft Azure
        uses: azure/login@v2
        if: env.USE_AZURE_LOGIN == 'true'
        with:
          creds: ${{ secrets.AZURE_CREDENTIALS }}

      - name: 4. Desplegar en Azure Blob Storage ($web)
        uses: azure/CLI@v2
        with:
          inlineScript: |
            az storage blob upload-batch \
              --account-name ${{ secrets.AZURE_STORAGE_ACCOUNT }} \
              --auth-mode key \
              --account-key ${{ secrets.AZURE_STORAGE_KEY }} \
              --destination '$web' \
              --source . \
              --overwrite true

      - name: 5. Notificar Despliegue Exitoso
        run: echo "Despliegue finalizado exitosamente en Azure."
01

Disparador Automático (Trigger)

Monitoreo de la rama main ante cada confirmación (commit) local realizada por el desarrollador.

02

Entorno de Compilación Seguro

Aprovisionamiento de un contenedor efímero ubuntu-latest en GitHub Actions con variables protegidas.

03

Autenticación Segura (Zero Secrets Exposure)

Uso de secrets.AZURE_CREDENTIALS cifrado con AES-256 en GitHub Secrets cumpliendo con la Fase 3.1.

04

Sincronización con $web

Copia diferencial atómica hacia el contenedor público de Azure Storage con actualización inmediata de caché.
